[h1]Play several mods together[/h1]
The official Mod Launcher can only start [b]one[/b] gameplay mod at a time: every gameplay mod contains all of the game's roughly 2000 script files, and the launcher stops as soon as two mods contain the same file ("error copying mod").

[b]TG3 ModLoader[/b] solves this. It looks at what each of your mods really changes compared to the original game and combines all these changes into [b]one[/b] mod. If two mods change different things in the same file, both changes are kept. The official Mod Launcher then starts this one combined mod.

[i]This is a small Windows program, not a mod that the game loads - you start it yourself (see "How to use").[/i]

[h2]Features[/h2]
[list]
[*][b]Combines any number of gameplay mods[/b] - down to single values, list entries, objects, actions and functions of the game scripts
[*][b]Texts in all languages[/b], screen layouts, pictures and sounds are handled too; new files of a mod are simply added
[*][b]Conflicts made easy:[/b] if two mods change the same setting differently, the mod higher in your list wins - or you pick the value yourself with one click: another mod's, the original game's or your own
[*][b]Checks its own work:[/b] verifies that every change of every mod made it into the result
[*][b]One click to play:[/b] prepares the official Mod Launcher (switches the combined mod on and the single mods off) and opens it
[*][b]Tells you when to combine again[/b], e.g. after a mod was updated in the Workshop
[*][b]Optional game test:[/b] starts the game, waits for the main menu and reports script errors and crashes
[*]A clear report of every combine, light and dark mode, nothing to install
[/list]

[h2]How to use[/h2]
[olist]
[*]Subscribe to this item and to the mods you want to play with.
[*]Start [b]TG3ModLoader.exe[/b]: open the official Mod Launcher, select [b]TG3 ModLoader[/b] in the list, click [b]Mod files[/b] and double-click [b]TG3ModLoader.exe[/b] in the folder that opens. On the first start it offers to put a shortcut on your desktop.
[*]Tick your mods and drag them into order - the mod at the [b]top[/b] wins when two mods change the same setting.
[*]Click [b]Combine & Play[/b]. The Mod Launcher opens with everything prepared - just click [b]Play[/b].
[/olist]
Maps don't need combining - switch them on in the Mod Launcher as usual. Leave "TG3 ModLoader" itself switched off in the Mod Launcher: it is a program, not a game mod (the ModLoader switches it off for you).

[i]Can't find the program?[/i] It is in your Steam library folder under [i]steamapps\workshop\content\311260\[/i] in the folder named like the number at the end of this page's address.

[h2]Good to know[/h2]
[list]
[*][b]Savegames:[/b] the game shows a mod id in the main menu and keeps savegames per mod id. The same mods in the same order always give the same id. If you change your selection, your older savegames belong to the previous id.
[*][b]Multiplayer:[/b] all players need the same mods in the same order (same mod id in the main menu).
[*][b]After a mod update[/b] combine again - the ModLoader tells you when.
[*]If a mod contains a mistake of its own (a script error), the ModLoader points it out. Such mistakes are there without the ModLoader too.
[*]Your settings and the combined mod are kept in [i]steamapps\workshop\content\311260\TG3ModLoader[/i], so updates of this item don't touch them.
[*]Already using the version from GitHub? This version uses the same settings and the same combined mod.
[/list]

[h2]Troubleshooting[/h2]
[list]
[*][b]The Mod Launcher says "Error copying / conflicting mod":[/b] a gameplay mod is switched on next to the combined mod ("MergedMod"). Tick it in the ModLoader and combine again, or switch it off in the Mod Launcher.
[*][b]The game crashes while loading:[/b] use [i]More > Test the game[/i] and read the notes in the report.
[*][b]A change of a mod is missing:[/b] look at the Conflicts tab - another mod may change the same setting.
[*][b]To stop using the ModLoader:[/b] choose [i]More > Remove from the Mod Launcher[/i], then unsubscribe.
[/list]

[h2]Safe and open source[/h2]

[list]
[*]It never changes the game or your mods. It only writes its own combined mod and the Mod Launcher's mod list (after making a backup of it).
[*]It doesn't connect to the internet, needs no admin rights and installs nothing. Windows 10/11 (.NET Framework 4.8 is part of Windows).
[/list]
